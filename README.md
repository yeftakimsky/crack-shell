## Steps Completed

1. Installed Cursor IDE.
2. Opened Cursor in browser and create account.
3. Opened Cursor in desktop and logged in.
4. Click: File - Open Editor Window.
5. Go to: View - Extensions or press "Ctrl + Shift + X".
6. Search "Claude Code" on the Extension in Marketplace.
7. Clicked "Install" and wait until the installment is finished.
8. Search "Codex" on the Extension in Marketplace.
9. Clicked "Install" and wait until the installment is finished.
10. Go to Github.com and create account.

14. Committed and pushed the repository to GitHub.
